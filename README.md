# 小壹的记忆花园

纯静态互动网站，可直接部署至 GitHub Pages，无需安装依赖或执行构建。

## 部署

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 `main` 分支与根目录 `/`。根目录的 `.nojekyll` 用于跳过 Jekyll 处理。保留文件名大小写及 `assets/` 目录结构。

网站使用相对资源路径与 `#/...` 路由，兼容 GitHub Pages 仓库子路径。

在线页面使用约 4.2 MB 的 720p 开场视频；原始 4K 视频保留供离线打开使用。离线图片备用脚本仅在 `file:` 协议下加载，避免阻塞在线页面初始化。

## 本地预览

在当前目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。也可使用原包中的双击入口离线打开。

## 记录保存

游戏进度、换装与纪念册数据保存在当前浏览器的 IndexedDB 中，不上传服务器，不跨设备同步。离线文件、本地预览及公开网址属于不同来源，存档互相独立；清除浏览器网站数据可能删除存档。

## 来源

基于用户提供的「小壹的记忆花园-可发送网站(1).zip」发布，保留原网站内容和交互。
